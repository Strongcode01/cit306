Project Report – CIT 306 GP 14

1. Introduction

The Departmental Student Information Board (DSIB) is a web platform developed to simplify communication within the Department of Computer Science, FUTO.

2. Objectives

  • Provide centralized departmental updates.
  • Enable authorized student registration.
  • Allow admin management of announcements and timetables.

3. Tools and Technologies

  • Django (Python framework)
  • HTML5, CSS3, JavaScript
  • PostgreSQL Database
  • Render.com for deployment

4. Implementation

The project follows the Django MVT architecture. The system includes authentication, announcements, events, timetable, and group member modules. Each module is managed through a dynamic admin interface.

5. Deployment

  1. Configured GitHub repository.
  2. Linked project to Render.
  3. Set up PostgreSQL database using DATABASE_URL.
  4. Ran migrations and deployed static files.

6. Challenges & Solutions

  • Database Resets: Solved by using PostgreSQL instead of SQLite.
  • Static File Loading: Fixed with Whitenoise integration.
  • Matric Validation: Implemented AllowedMatric model for restricted signup.

7. Results

The deployed system allows real-time access to departmental announcements, events, and timetables. Students can securely register and view group information.

8. Conclusion

The project successfully achieved its goal of providing a digital information board. It’s scalable, secure, and user-friendly.

9. Recommendations

  • Integrate notifications (email/SMS).
  • Add result management functionality.
  • Adopt mobile app version for wider accessibility.
