Project Documentation

This section provides the technical documentation of the Departmental Student Information Board (CIT306 GP14) developed using Django.

System Overview

The project implements a departmental information board for announcements, events, timetables, and group project credentials.

Architecture

  • Framework: Django 5.x (Python)
  • Frontend: HTML5, CSS3, JS
  • Database: PostgreSQL (Render)
  • Hosting: Render.com

Key Modules

  • Accounts: Handles user authentication and profile management.
  • Board: Manages announcements, events, and timetables.
  • Team: Displays group member credentials.
  • Core: Contains static pages like home, contact, documentation, and report.

Deployment Steps

  1. Push code to GitHub.
  2. Create a Render web service.
  3. Add environment variables (SECRET_KEY, DATABASE_URL, DEBUG=False).
  4. Run migrations and collect static files.

Security Measures

  • CSRF protection for all forms.
  • Password hashing using Django’s PBKDF2 algorithm.
  • Restricted signup via AllowedMatric validation.

Future Improvements

  • Integrate email notifications for announcements.
  • Add result management and lecturer uploads.
  • Implement live notifications using WebSockets.
